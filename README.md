# PhD_2
This is the r code for article entitled: Analysis and Ranking Strategies for Underperforming Universities. This repository contains the source code, datasets, and implementation procedures developed for a PhD research study which investigated the relationship between Wikidata metadata quality and Webometrics ranking of university performance. The project focuses particularly on analysing underperforming universities through machine learning approaches which included the Decision Tree Classification and the Extreme Gradient Boosting (XGBoost). The study objective was to identify relevant Wikidata Identifiers and Statements that may contribute to the institutional visibility and ranking performance. The repository is provided in order to support transparency, reproducibility, and future research development.
